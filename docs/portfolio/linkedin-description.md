# LinkedIn project description

NurtureOps AI is a synthetic-data childcare operations portfolio project focused on trust boundaries, not a live childcare service. I clean-room rebuilt the application as a Next.js/Supabase architecture after auditing three supplied source archives for provenance, licence, browser-security, financial, and AI risks.

The project includes role-specific director, educator, and guardian experiences; idempotent attendance with a bounded offline queue; deterministic bigint billing and immutable issued invoices; a 62-table PostgreSQL schema with explicit grants, forced row-level security, relationship-aware access, and private storage; and a Care Copilot that can only return typed, evidenced proposals for human review.

All records are fictional. No live payment or messaging provider is connected, AI is disabled or synthetic-only, and the project makes no compliance, client, usage, or business-outcome claims.

Portfolio demonstration: <https://nurtureops-ai.vercel.app>. The public release remains noindex and synthetic-data-only.
