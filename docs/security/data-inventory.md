# Data inventory

This is a purpose/visibility register for the intended system. The repository stores only fictional seed values. Production retention periods require owner and jurisdiction approval.

| Data class            | Examples / tables                                                     | Purpose                                      | Default visibility                                                     | Retention/deletion posture                                         |
| --------------------- | --------------------------------------------------------------------- | -------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Tenant/identity       | organizations, locations, profiles, memberships, role_grants          | Account and access administration            | Self, tenant operators, auditors as scoped                             | Membership history retained for audit; exact period unresolved     |
| Invitations           | normalized email, token hash, role, expiry                            | Closed onboarding                            | Inviter/admin; token never stored plaintext                            | Expire 5 min-7 days; revoke/consume; purge schedule unresolved     |
| Child directory       | display name, DOB, location, version                                  | Enrolment and operations                     | Assigned operators; related guardians                                  | Active relationship plus approved statutory/business period        |
| Guardian relationship | guardian, child, view flags, dates                                    | Family authorization                         | Directors and relationship subject                                     | Preserve relationship history; deletion/legal hold unresolved      |
| Emergency/pickup      | encrypted contact payload, authorized pickup validity                 | Emergency and safe handoff                   | Purpose-limited operators/related guardians                            | High sensitivity; review/revoke; period unresolved                 |
| Care/medical support  | care profile, allergies, instructions, medication authorization/admin | Authorized care execution                    | Assigned staff/directors; not AI by default                            | High sensitivity; owner/jurisdiction policy required               |
| Consents              | type/version/decision/time/supersedes                                 | Proof of decision                            | Director, related guardian, auditor                                    | Immutable history; legal period unresolved                         |
| Workforce             | assignments, shifts, qualifications                                   | Staffing and ratios                          | Directors; assigned staff subset                                       | Employment/jurisdiction policy unresolved                          |
| Attendance            | sessions, events, corrections, offline receipts                       | Presence, handoff, billing input             | Assigned staff/directors; related guardian; billing/auditor subset     | Append-only correction history; period unresolved                  |
| Daily care            | structured entries, drafts, reports, visibility                       | Care operations and approved parent timeline | Assigned operators; explicitly published related guardian              | Draft/published retention policy unresolved                        |
| Safety                | incidents/history, restricted notes, medication records               | Incident review and care accountability      | Restricted directors/auditors; guardian only through reviewed workflow | Immutable history; safeguarding/legal review required              |
| Communication         | threads, participants, messages, announcements, preferences           | Family/team communication                    | Explicit participants and authorized operators                         | Provider/retention policy unresolved; no provider active           |
| Billing               | contracts, plans, invoice lines, payments, credits                    | Deterministic charges and records            | Billing roles/directors; related billing guardian                      | Issued records immutable; tax/statutory period unresolved          |
| Documents             | private object path, metadata, child relation                         | Consents, reports, operational files         | Purpose-limited RLS and signed access                                  | Private bucket; expiry/legal hold policy unresolved                |
| Audit/security        | actor, request, type, entity, result class, time                      | Accountability and incident detection        | Directors/auditors/security operators                                  | Content-free immutable record; period unresolved                   |
| Exports/deletion      | job state, scope, expiry/error class                                  | Data rights and operations                   | Recently authenticated privileged roles                                | Expire object and log completion; backup propagation unresolved    |
| AI governance         | run metadata, model/tool versions, field manifest, approval           | Cost/safety/accountability                   | Actor/director/auditor                                                 | No raw prompts/provider bodies/child narratives; period unresolved |

Data must not enter query strings, analytics, public storage, provider calls, logs, errors, screenshots, or AI unless its purpose and authorization are explicitly approved.
